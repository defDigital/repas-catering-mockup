# Repas Catering — pagina Bedrijfsevents

Mockup van één extra pagina voor repascatering.be: een landingspagina voor
zakelijke klanten. De vormgeving, het contactblok en de footer zijn
overgenomen van de huidige site.

Bekijken: https://defdigital.github.io/repas-catering-mockup/bedrijfsevents.html

## Inhoud

De teksten staan in `src/content/`, met per inhoudstype een schema in
`src/content.config.ts`. De pagina zelf staat in
`src/pages/bedrijfsevents.astro` en de opmaak in `src/styles/global.css`.

## Draaien

```bash
npm install
npm run dev
```
